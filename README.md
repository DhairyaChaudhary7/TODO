# 🚀 SmartTask AI - 3D To-Do List Web App

A modern, responsive, and interactive productivity web application built using HTML, CSS, and JavaScript.

SmartTask AI helps users organize tasks, track progress, maintain productivity streaks, and stay motivated with AI-powered task suggestions.

---

## ✨ Features

### 📋 Task Management
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Due date support
- Real-time task updates

### 🎨 Modern UI/UX
- 3D Glassmorphism Design
- Fully Responsive Layout
- Smooth Animations
- Hover Effects
- Animated Particle Background
- Cursor Glow Effect

### 🌗 Theme Support
- Dark Mode
- Light Mode
- Theme Preference Saved in Local Storage

### 📊 Productivity Tracking
- Circular Progress Indicator
- Completed Task Counter
- Total Task Counter
- Daily Streak Counter

### 🎉 Interactive Features
- Confetti Celebration on Task Completion
- Voice-to-Text Task Input
- AI Task Suggestions
- Animated Dashboard

### 💾 Data Persistence
- Local Storage Support
- Tasks Remain Saved After Refresh
- Theme Settings Saved Automatically

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Web Speech API
- Particles.js
- Canvas Confetti
